# Study Copilot

一期 A：注册引导、今日任务、可靠专注、学习记录、伙伴与控制台。

- 后端：Java 17、Spring Boot 3.3.4、PostgreSQL 16、Redis、MinIO。
- 前端计划：Vue 3、Vite、Pinia、Vue Router；当前 `web/` 尚未实现。
- 当前交付是后端代码，按用户要求没有执行本轮测试、编译、迁移或联调。

从 [文档导航](docs/README.md) 按工作查找资料。常用入口：

| 查看当前交付状态 | [后端交付说明](docs/04-交付验收/一期A后端交付说明.md) |
| 开发前端、调用接口 | [前端接口对接](docs/03-接口对接/前端接口对接.md) |
| 配置本地后端环境 | [后端本地开发](docs/02-开发指南/后端本地开发.md) |

# 一期 A 最小可用产品前端对接说明

[返回文档导航](../README.md)

本文根据当前源码整理接口约定，不代表接口已经运行验收。本轮后端改动尚未编译、启动、执行迁移或测试。一期 A 的核心流程是：账户 → 科目与任务 → 专注 → 记录与控制台。当前交付范围见 [后端交付说明](../04-交付验收/一期A后端交付说明.md)，前端目录尚未实现。

## 本地连接

后端使用 Java 17、Maven 和 PostgreSQL 16。按照 [本地开发说明](../02-开发指南/后端本地开发.md) 配置进程环境变量，默认 HTTP 端口为 `8080`。后续获准启动应用时，应先由 Flyway 执行 V6、V7 迁移，补齐当前接口依赖的数据库结构。

计划使用 Vue 3/Vite 开发前端。在 Vite 开发服务器中，将 `/api` 代理到 `http://127.0.0.1:8080`，页面通过相对路径 `/api/...` 请求接口。生产环境也保留同源 `/api` 代理，避免额外配置跨域部署。

## 统一响应与身份认证

接口使用 `Result<T>` 响应结构，包含 `code`（`"0"` 表示成功）、`message`、`data`、`traceId`、`retryable`、`fieldErrors`、`currentVersion` 和 `currentSession`。前端同时处理 HTTP 状态码和业务错误码，请求失败时保留用户已输入的草稿。

认证、设置和科目接口的数据对象使用驼峰命名。任务和专注接口通过 JDBC 返回的记录使用数据库下划线字段，例如 `subject_id`、`target_date`、`start_at`、`scheduled_end_at`；请求体仍使用驼峰命名。建议在前端接口层统一适配，不要递归改写任意 JSON 内容或用户输入。

除注册、登录、刷新令牌和读取账户恢复信息外，请求需携带 `Authorization: Bearer <accessToken>`。JSON 请求使用 `Content-Type: application/json`；上传图片时由浏览器自动设置多部分表单边界。资源归属由当前登录用户确定，请求体不要传入资源所有者 ID。

每次逻辑操作生成一个请求标识，例如使用 `crypto.randomUUID()`，超时重试时复用该标识。注册、完成引导、专注与休息写操作、创建补录记录必须传入 `Idempotency-Key`。创建任务也支持此请求头，前端应始终传入并在重试时复用。未传幂等键且发生结果不确定的超时时，应先核对任务列表，再决定是否重试。

收到 HTTP 429 时保留表单，并根据 `retryAfterSeconds` 展示剩余等待秒数；响应头 `Retry-After` 也提供该值。收到 HTTP 401 时，最多发起一次共享的令牌刷新请求，保存轮换后的**访问令牌和刷新令牌**，再用原幂等键重放失败请求。刷新失败时保留草稿并返回登录页。不要通过此刷新流程自动重试登录或账户注销请求。

## 首次注册与新手引导

| 请求方法与路径 | 请求内容与行为 |
| --- | --- |
| `POST /api/auth/register` | `{username,password,email?}`，另传 `Idempotency-Key` |
| `POST /api/auth/login` | `{username,password}` |
| `POST /api/auth/refresh` | `{refreshToken}` |
| `POST /api/auth/logout` | `{refreshToken}`；成功后清理本地账户状态 |
| `GET /api/auth/recovery-info` | 返回受邀内测实际配置的人工恢复渠道；未实现公开邮件重置 |
| `GET /api/onboarding/progress` | 完成引导时需要响应中的 `data.version` |
| `POST /api/onboarding/complete` | 跳过引导可传 `{version,skip:true}`，另传 `Idempotency-Key` |

注册、登录、刷新令牌返回 `accessToken`、`refreshToken`、`userId`、`username` 和 `nextRoute`。注册时已创建高数、英语、政治、专业课四门科目、用户设置和伙伴，初始默认科目为高数。根据 `nextRoute` 进入引导、控制台或恢复正在进行的专注。跳过引导不能阻止用户开始专注。

密码要求为 8–64 个字符，且 UTF-8 编码后不超过 72 字节。新用户名支持 4–30 位 ASCII 字母、数字或下划线，规范化时去除首尾空格并忽略大小写；登录仍兼容历史账户名称。不要记录密码、令牌或完整请求体。

## 任务、科目与设置

| 请求方法与路径 | 请求内容与行为 |
| --- | --- |
| `GET /api/subjects` | 返回科目的 `id`、`name`、颜色、归档状态和 `version`；新专注使用未归档科目 |
| `GET /api/settings` | 返回目标与日期、时区、默认科目、默认专注时长、显示偏好和 `version` |
| `PUT /api/settings` | 必须包含 `version`，例如 `{version,focusMinutes:25,theme:"SYSTEM"}`；保存后重新读取 |
| `GET /api/tasks?targetDate=YYYY-MM-DD&status=ALL` | 查询指定学习日，可传 `subjectId`；返回 `items`、完整 `counts`、`completedCount`、`validCount`、`completionRate` |
| `POST /api/tasks` | `{title,subjectId,targetDate,plannedPomodoros:1,priority:2}`；返回资源的 `id` 和 `version` |
| `PUT /api/tasks/{id}` | `{expectedVersion,title?,subjectId?,targetDate?,plannedPomodoros?,priority?}` |
| `POST /api/tasks/{id}/complete` | `{expectedVersion}`；用户确认同时完成子任务后才加入 `completeChildren:true` |
| `POST /api/tasks/{id}/reopen` | `{expectedVersion}` |
| `POST /api/tasks/{id}/cancel` | `{expectedVersion}` |
| `DELETE /api/tasks/{id}?expectedVersion=N` | 返回 `undoUntil` 和包含新版本号的已删除 `task` |
| `POST /api/tasks/{id}/restore` | `{expectedVersion}`，使用删除响应中的版本号；撤销窗口为 5 秒 |

初始选中日期使用 `/api/dashboard` 返回的 `learningDay`，它可能与浏览器的自然日期不同。任务完成与专注完成分开处理，由用户决定是否把任务标记为完成。

`VERSION_CONFLICT` 对应 HTTP 409、业务码 `SC_001005`。发生冲突时保留输入，读取最新资源，让用户决定如何重新应用修改，不要自动覆盖。当前已包含父子任务联动和重复任务范围编辑代码，但本轮代码交付未执行运行验收。

## 专注与学习记录

| 请求方法与路径 | 请求内容与行为 |
| --- | --- |
| `POST /api/focus/start` | `{subjectId,taskId?,minutes:25}`，另传幂等键；专注时长为 15–90 分钟 |
| `GET /api/focus/current` | 返回 `{serverNow,session,pendingResults}`；无进行中会话时 `session` 为 `null` |
| `POST /api/focus/{id}/complete` | 可传空 JSON，另传幂等键；服务端拒绝在计划结束时间前完成 |
| `POST /api/focus/{id}/end-early` | `{claimPartialReward:true}`，另传幂等键 |
| `POST /api/focus/break/start` | `{mode:"SHORT",minutes:5}` 或 `{mode:"LONG",minutes:15}`，另传幂等键 |
| `POST /api/focus/break/end-and-start` | 请求体同开始专注，另传幂等键；原子地结束休息并开始专注 |
| `POST /api/focus/{id}/presentation/claim` | `{deviceId}`；每个浏览器标签页使用独立标识 |
| `POST /api/focus/{id}/presentation/ack` | `{deviceId}`；确认成果已展示 |
| `GET /api/focus/records?learningDate=YYYY-MM-DD&page=1&pageSize=20` | 可传 `subjectId`；省略日期时使用当前学习日 |
| `POST /api/focus/records/manual` | `{subjectId,taskId?,startAt,endAt}`，另传幂等键；时间使用完整 ISO 格式的 UTC 时刻 |
| `PUT /api/focus/records/{id}` | 补录记录字段加 `expectedVersion` |
| `DELETE /api/focus/records/{id}?expectedVersion=N` | 返回 `undoUntil`、`recordId` 和新 `version` |
| `POST /api/focus/records/{id}/restore` | `{expectedVersion}`，使用删除响应中的版本号；撤销窗口为 5 秒 |

倒计时根据 `serverNow` 和 `scheduled_end_at` 计算，再通过浏览器单调时钟推进。刷新页面、重新连接、标签页可见状态变化时重新查询当前会话。前端倒计时归零不能视为奖励已保存。进行中状态最多每 5 秒轮询一次，同一时间仅保留一个请求；写入或结算后刷新控制台。不要自动开始下一次专注或休息。

常见冲突：`SESSION_EXISTS` 为 HTTP 409、`SC_007004`，根据 `currentSession` 提供恢复入口；`SESSION_NOT_DUE` 为 HTTP 409、`SC_007005`，重新查询当前会话；`TIME_OVERLAP` 为 HTTP 409、`SC_007006`，冲突详情沿用 `currentSession` 字段，前端保留补录输入。

补录时长必须为 1 分钟至 4 小时，结束时间不能晚于当前时刻，且不得与有效或预留的专注区间重叠。补录不发经验，也不增加完整番茄次数。`TIMER` 来源记录的时间不能编辑或删除。记录列表按学习日切片，需同时展示当天切片与原始会话区间，避免在每天重复计入整段会话。

## 控制台、伙伴与个人资料

`GET /api/dashboard` 返回 `learningDay`、`ruleVersion`、`serverNow`、`currentSession`、`stats`、`weeklyGoal`、`examDate`、`tasks`、`subjectDistribution`、`recentRecords`、`pet` 和 `dataVersion`。可选模块使用 `status: OK|EMPTY|ERROR` 及 `retryable` 包装结果；`ERROR` 不能显示为数值零。若响应的 `dataVersion` 小于已接受状态的版本，应丢弃该响应。

`GET /api/pet/status` 和 `GET /api/pet/options` 分别提供成长状态和可选伙伴。`POST /api/pet/switch` 的请求体是 1–5 的 **JSON 数字**，不是对象；切换伙伴保留经验。

`GET /api/account/profile` 返回 `username`、`nickname`、`avatarUrl`、`version`。`PUT /api/account/profile` 接收 `{nickname,expectedVersion}`。通过 `POST /api/upload/image` 上传文件时，会同时设置当前头像并递增资料版本，上传后重新读取资料。获取返回的图片路径时需携带访问令牌，再使用 Blob URL 展示。

`PUT /api/account/password` 接收 `{currentPassword,newPassword}`，并撤销已有登录会话。`POST /api/account/deletion` 接收 `{currentPassword,confirmDeletion:true}`，返回 HTTP 202 及 `{jobId,status:"PENDING"}`，随后撤销账户访问。注销成功后不要自动刷新重试，应清除令牌、用户缓存和 Blob URL。

最小可用产品前端以控制台、任务、专注为主导航，记录、伙伴、个人资料、设置作为次级入口。B/C 接口及旧版 `/api/pomodoro` 路由默认不可用。

## 一期 A 已补齐的接口约定

- 任务默认查询当前学习日，第 1 页、每页 50 个根任务，每页最多 100 个；计数覆盖完整筛选结果。有效计划数为零时，`completionRate` 为 `null`。通过 `GET /api/tasks/overdue`、`/unplanned`、`/{id}` 查询待处理任务、无日期任务和任务详情。创建时可明确传 `targetDate:null`，快速创建可省略 `subjectId` 或 `plannedPomodoros`。子任务继承父任务的科目和日期，不能单独修改。父任务实际时长与番茄次数会对关联父子任务的会话去重汇总。
- `PUT /api/tasks/{id}` 支持 `scope:"THIS_ONLY"`（默认，仅这次）和 `"THIS_AND_FUTURE"`（这次及以后）。后者同时需要任务 `expectedVersion` 和模板 `templateExpectedVersion`，修改所选未开始实例及后续符合条件的实例，保留已开始、已完成和已独立覆盖的实例。重复模板接口为 `/api/tasks/repeat-templates`；`effectiveDate` 包含当天，直接修改模板时默认从明天生效。暂停或取消模板后，已有实例保留供用户处理。
- 顺延请求为 `{items:[{id,expectedVersion}],conflictChoice}`，最多明确选择 500 个根任务，父任务与其子任务一起移动。冲突策略为 `KEEP_BOTH`（两者保留）或 `KEEP_TODAY_CANCEL_OLD`（保留今天并取消旧任务）。`/api/tasks/carry-over/{batchId}/undo` 原子撤销整批操作；任一变更行再次编辑后，整批撤销失败。任务删除恢复和父任务取消重开使用准确的变更批次关联子项。
- `GET /api/focus/{id}` 返回本人会话，`/{id}/result` 返回最终成果；恢复时会补偿处理已到期会话。`POST /api/focus/break/{id}/end` 携带幂等键显式结束休息。成果包含 `rewardBreakdown`、`todayFocusSeconds`、新旧等级、`completedPomodoros`、`suggestedBreak` 和 `dataVersion`。提前结束时，省略半奖字段默认视为申请半奖，同时遵循会话开始时保存的半奖偏好。
- `POST /api/focus/records/manual/preview` 接收补录字段，返回按学习日分配的秒数。编辑预览时补充 `recordId`、`expectedVersion`，在重叠检查中排除自身。补录支持最长 500 字符的 `note`。记录分别提供切片的 `awarded_exp`、`valid_seconds` 和整段会话的 `session_awarded_exp`、`session_valid_seconds`，不要按天重复累加整段会话。
- 设置返回 `activeTimezone`、`activeDayStartHour`、`activeRuleVersion` 和可空的 `pendingLearningRule`。用户保存的偏好可能要到下一个旧规则学习日边界才生效，页面应展示该生效时间。明确传入 JSON `null` 可清空 `examDate`、`weeklyGoalMin`、`dailyAvailMin`。新增独立偏好为 `soundEnabled`、`animationsEnabled`、`partialRewardsEnabled`；前端音效和动画仍需优先遵守 `muted`、`reduceMotion`。
- 引导进度保存可恢复标记与已确认草稿。实际伙伴、设置、科目变更应调用各自接口，再保存进度标记；任意 `confirmedData` 不会直接覆盖对应资源。`GET /api/onboarding/plan` 返回最近一次导入的只读阶段摘要，控制台可选 `plan` 模块返回相同摘要。
- 控制台提供 `learningDayInfo`（实际边界时刻）、`goal`（自然日倒计时）、完整任务指标、单独的 `runningEstimatedSeconds`、周目标实际比例与限制范围后的比例，以及 `subjectDistribution` 的 `visibleItems`、`otherItems` 和完整数据列表。各模块错误独立展示；服务端使用数据库保存点隔离可选模块查询失败。
- 每个浏览器标签页使用独立的成果展示 `deviceId`，例如保存在 `sessionStorage` 中。服务端向一个设备标识授予展示资格，前端也需防止响应重试导致已展示动画再次播放。

以上内容描述当前源码约定。本轮未执行编译、测试、启动、数据库迁移或前后端联调。

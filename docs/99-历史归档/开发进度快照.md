- 任务 5 的 V4 为任务增加模板身份与来源，跨批次按所有者、模板、条目、不可变导入学习日唯一，并支持版本和软删除。稳定条目标识在改期后仍识别同一导入任务；不同解释需要明确修改重复导入策略或迁移。

- PostgreSQL 16 为唯一事实来源，Redis 清空或不可用不应丢失权威状态，MinIO 仅存储头像对象。
- 集成测试使用隔离的 `study_copilot_test` 数据库和 `study-copilot:test:` Redis 前缀，H2、Testcontainers 不在范围内。
- 默认与测试配置隐藏全部 B/C 接口，允许为编译修复控制器，不实现其功能。
- `dataVersion`、幂等键、乐观版本、行锁、PostgreSQL 排斥约束与部分唯一约束属于共享约定，不得各任务自行解释。

- `t_user.normalized_username` 全局唯一。原简述中的 `(user_id, normalized_username)` 不成立，因为 `t_user.id` 已唯一，该组合不能阻止相同登录名；不新增冗余 `user_id` 列或键。

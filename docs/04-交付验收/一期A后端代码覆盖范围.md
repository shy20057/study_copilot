# 一期 A 后端代码交付范围

[返回文档导航](../README.md)

用户明确将本轮交付限定为编写后端代码，不包含测试、编译、应用启动、数据库迁移执行、联调和部署。本文记录源码覆盖情况，**表内任何一项都不代表运行验收通过**。本轮没有新增或修改测试源码，历史测试结果也不作为当前版本的验证证据。

| 需求范围 | 后端代码覆盖情况 | 待验证事项或其他层工作 |
| --- | --- | --- |
| A.1 / A.13 设置 | 规则版本、延迟生效边界、当前与待生效规则响应、可空目标、独立反馈偏好 | 时区、夏令时、规则切换场景留待后续获准运行；前端在保存前展示影响 |
| A.3 认证 | 受邀内测的注册、登录、刷新、退出、改密；初始化科目、设置、伙伴；持久化账户与来源退避；结合会话状态撤销访问 | 公开邮件验证与重置不属于当前受邀内测模式；私有部署、访问控制、真实人工支持渠道由运维配置 |
| A.4 引导 | 可恢复进度、跳过、版本化七日预览与导入、稳定条目标识、只读阶段摘要 | 前端通过对应接口修改伙伴、设置、科目，再保存引导标记；预览确认页面由前端实现 |
| A.5 任务 | 分页与计数、父子继承和完成联动、可选科目与预计番茄及日期、待处理与无日期查询、版本、排序、取消与删除批次、原子撤销 | A-09–A-13、A-35 的任务与并发用例未执行 |
| A.5 重复与顺延 | 两种编辑范围、不可变实例身份、保留已开始及已完成和独立覆盖实例、当日生成、活跃用户调度、不补离线历史欠账、父子整体顺延与原子撤销 | 跨日、冲突、并发场景未执行 |
| A.6–A.7 专注 | 唯一槽位、配置快照、服务端时间、到期扫描、提前结束、休息与恢复、确定成果、展示资格领取 | A-14–A-24、A-29、A-34、A-36 留待后续服务端与浏览器验证；前端按标签页协调展示资格，不自动开始下一会话 |
| A.8 奖励与伙伴 | 累计整数秒分配、历史规则快照、每日奖励上限与明细、固定完整番茄归属日、十级四阶段、切换不重置经验 | 奖励事务与并发场景未执行；五个伙伴的插画与动画属于前端素材 |
| A.9 记录 | 历史补录、预览、备注、归属校验、左闭右开区间重叠检查、编辑与删除及恢复、补录无奖励、切片与完整会话信息分页 | A-25–A-31、A-40–A-41 未执行 |
| A.2 / A.10 控制台 | 一致账本指标、完整根任务计数、展示 6 条任务、运行预估独立显示、周进度、自然日倒计时、5 门科目及其他、近期记录、阶段摘要、保存点隔离模块错误、`dataVersion` | A-43–A-51 未执行；前端需拒绝旧版本响应，区分 `EMPTY` 与 `ERROR` |
| A.13 隐私 | 资料版本、经校验的私有头像、密码确认注销、可重试的本人数据清理、最小审计占位记录 | 存储与缓存实际故障和恢复未执行；备份按实际配置的保留期过期 |
| A.14 运维 | 受保护指标、固定范围标签、Dockerfile、数据库备份与隔离恢复脚本、恢复说明 | 性能、服务重启、备份、外部对象备份、恢复演练、监控部署均未执行 |
| A.11 / A.12 / A.15 | 服务端偏好、错误、版本约定，可恢复状态和运维计数器 | 响应式鲸蓝界面、键盘访问、对比度、减少动态效果、浏览器通知权限、可用性及产品行为埋点由前端实现 |

默认控制器范围仍仅包含一期 A。已有 B/C 和旧版控制器配置保持默认关闭，本轮未实现 B/C 生产行为。仅能通过非默认配置访问的占位服务不属于一期 A 实现范围。

文档入口与当前接口详情见 [交付说明](一期A后端交付说明.md) 和 [前端对接说明](../03-接口对接/前端接口对接.md)。V6、V7 为新增且尚未执行的迁移。后续验证需另行获得用户明确批准，并依据新执行结果判断，本文不构成执行测试的授权。

## 阅读与维护约定

- 产品范围与业务规则看「产品需求」，当前实际接口看「接口对接」，当前实现状态看「交付验收」。接口约定与产品目标有差异时，需结合源码和交付边界判断。
- 历史归档只供追溯，其中的测试授权、执行流程、任务勾选和旧结论均只适用于记录时刻，不构成当前执行指令，也不能证明当前版本已经验证。
- 新文档放入对应分类目录，使用中文描述用途的文件名，并在本页补充入口。同一主题优先更新已有文档，迁移文件时同步更新引用。
- 备份、恢复和测试脚本的入口见 [脚本说明](../scripts/README.md)。文档中的命令是操作参考，是否执行遵循用户当前授权。
